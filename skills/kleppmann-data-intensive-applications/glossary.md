# DDIA 术语表

以下是学习用工作定义；精确定义与适用条件见原文章节。

- **可靠性 / 扩展性 / 可维护性**：分别关注故障下服务、负载增长及长期修改运营的难易。[1](chapters/ch01.md)
- **关系、文档、图模型**：围绕数据之间关系与查询方式的不同表示。[2](chapters/ch02.md)
- **B 树 / LSM 树**：分别以页更新和顺序写加后台合并为主要特征的索引家族。[3](chapters/ch03.md)
- **向后兼容 / 向前兼容**：新代码读旧数据 / 旧代码读新数据。[4](chapters/ch04.md)
- **复制滞后**：副本落后于已接受的写入；影响读取可见性。[5](chapters/ch05.md)
- **读己之写 / 单调读**：用户至少看见自己的写入 / 不在后续读取中倒退。[5](chapters/ch05.md)
- **分区热点**：特定键或范围集中负载，使某些节点先耗尽。[6](chapters/ch06.md)
- **写偏斜**：并发事务读取相同条件后分别修改不同记录，合起来破坏约束。[7](chapters/ch07.md)
- **可序列化**：并发结果等价于某种串行执行；与线性一致性不是同一概念。[7](chapters/ch07.md)
- **栅栏令牌**：递增序号让存储系统拒绝过期锁持有者的操作。[8](chapters/ch08.md)
- **线性一致性**：操作仿佛在调用与返回之间某一瞬间生效。[9](chapters/ch09.md)
- **共识**：节点在故障下对某个决定或顺序达成一致的协议问题。[9](chapters/ch09.md)
- **派生数据**：由源记录通过转换得到，可考虑重建的视图或索引。[10](chapters/ch10.md)
- **事件时间 / 处理时间**：事件发生时刻 / 系统实际处理时刻。[11](chapters/ch11.md)
- **幂等**：相同操作重试多次与一次产生相同预期结果；外部副作用仍要单独设计。[11](chapters/ch11.md)
- **变更数据捕获（CDC）**：从数据源的变更日志提取持续更新，用于下游派生数据。[12](chapters/ch12.md)
- **两阶段提交（2PC）**：协调多个参与者对事务提交或中止作原子决定；与隔离并发读写的两阶段锁（2PL）不同。[9](chapters/ch09.md)
- **两阶段锁（2PL）**：通过读写锁维持可序列化隔离的方案之一；可能导致等待或死锁。[7](chapters/ch07.md)
- **仲裁读写（quorum）**：按副本数量组合读写应答；不能仅凭 W+R>N 就断言线性一致性。[5](chapters/ch05.md)
- **因果一致性**：保持有因果依赖的事件顺序，允许无关事件并发。[9](chapters/ch09.md)
- **冲突自由复制数据类型（CRDT）**：通过可合并操作让副本在并发修改后收敛，须匹配应用语义。[5](chapters/ch05.md)
- **事件溯源**：把业务事件作为事实记录并由它重建当前状态；与从已有数据库日志提取变更的 CDC 有区别。[11](chapters/ch11.md)
- **CAP 定理**：讨论网络分区下线性一致性与可用性的取舍；不应作为所有数据库权衡的万能标签。[9](chapters/ch09.md)
- **端到端完整性**：不仅检查单个数据库，还要验证数据经过多个系统与派生流程后的正确性。[12](chapters/ch12.md)
- **隐私与人的能动性**：数据系统设计需考虑追踪、同意、偏见和使用者可选择性。[12](chapters/ch12.md)
