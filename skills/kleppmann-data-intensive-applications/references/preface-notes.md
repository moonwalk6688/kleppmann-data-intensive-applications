# 卷首与阅读边界

**来源**：用户提供的 OCR Markdown 第 1—480 行；封面图片无法核对。

作者的目标是解释数据存储和处理技术背后的长期原则与取舍，帮助工程师在数据库、缓存、搜索索引、消息队列、批处理、流处理之间选型，并理解工具组合后的整体行为。这里的“数据密集型”指主要难题来自数据量、复杂度或变化速度，而不是 CPU 计算量。书不提供具体软件安装或 API 教程，也没有全面覆盖部署、运维和安全；这几类议题不能把本书当唯一依据。

全书三部分：第 1—4 章讨论可靠性、扩展性、可维护性、数据模型、存储引擎和编码演化；第 5—9 章讨论复制、分区、事务、分布式系统故障、一致性与共识；第 10—12 章讨论批/流处理、派生数据和未来系统。作者反对以“大数据”等模糊标签替代工作负载、系统边界与具体保证的讨论。

原版为 2017 年版本。书中软件、云服务、硬件数字和市场情形有历史时点；本技能应用于现行系统时要用当前官方资料与实测核验。OCR 中的外链图片不是已读图像，印刷页码不能由 OCR 行号代替。
