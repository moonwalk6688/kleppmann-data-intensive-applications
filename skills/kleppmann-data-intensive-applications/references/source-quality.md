# 来源、覆盖与解释边界

唯一材料为用户本地提供的《Designing Data-Intensive Applications》PaddleOCR Markdown，清单记录 17,260 行及 SHA-256。卷首、第 1–12 章、各部分导言和术语表的 OCR 可见文字已按顺序核读，并据此重写章节笔记。长篇索引（第 11,507–17,240 行）也已逐行核读；它主要是检索线索，具体论证仍须回到正文。作者与书末版权信息已核读。

原始印刷 PDF 和外链图片没有提供可核验内容，OCR 的公式、图表、代码和分页可能有误。本技能不声称已校对纸书的每一个字，也不把计算机扫描过全文等同于人工阅读。章节和原文哈希见 [source-manifest.json](source-manifest.json)。引用原句、具体算法细节和数值时，使用 [回查脚本](../scripts/read_source.py) 对照匹配哈希的本地 OCR；若无原文，应说明无法核验。

本书为 2017 年版。原理可用于架构思考，具体数据库产品的现行版本、实现和性能须另查当前官方资料。
